# Nightreign Relic Extractor — Browser MVP

PS5等の録画動画から、遺物詳細パネルの画像を自動抽出する静的Webアプリです。OCRはありません。動画はサーバーに送信せず、ブラウザ内で処理します。

## 使い方

1. `index.html` をChromeまたはEdgeで開きます。ローカルファイルからの動作が制限される場合は、フォルダ内で `python3 -m http.server 8000` を実行して `http://localhost:8000` を開いてください。
2. 動画を選択。プレビュー位置を動かし、遺物詳細欄が表示されるフレームに合わせます。
3. 緑枠をドラッグして、遺物名と効果の領域を囲みます。初期値は提供された1280x714の画面を基準にしています。
4. 最初は `終了（秒）=60` で試します。初期設定は step=0.1、stable=0.3、threshold=1.0 です。
5. 解析を開始。抽出画像を確認し、不要な候補のチェックを外してZIP保存します。

## 注意点

- Python/OpenCV版の検出アルゴリズムをブラウザ向けに移植した試作版です。ブラウザのシーク精度や画像の縮小・ぼかしが異なるため、Python版と同じ33枚になる保証はありません。まず60秒分で比較してください。
- HTML Videoのseekを逐次行うため、9分の動画は時間がかかる場合があります。Chrome/Edgeデスクトップ推奨。
- 動画のフレームレートが不明なので、CSVの `frame` 欄は空欄です。`time_seconds` はシーク要求時刻の近似値です。
- 長い動画では画像をメモリに保持します。ブラウザのメモリ不足に注意してください。
- ZIP作成にはCDN版JSZipを使用するため、初回はインターネット接続が必要です。動画や抽出画像をCDNに送信することはありません。
- ローカルで完全オフライン利用したい場合はJSZipをダウンロードしてローカル参照に変更してください。
- 同一の効果欄が連続した場合や遷移が速い場合は取りこぼす可能性があります。結果を目視確認してください。

## 公開

`index.html`, `style.css`, `app.js` をGitHub Pagesに配置すればURLで共有できます。動画のアップロード先となるバックエンドは不要です。
